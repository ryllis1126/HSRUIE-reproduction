## P0：可靠 checkpoint 推理认证

**目标**：确认当前发布代码 LOW-off 和指定六份权重可重复生成来源明确的样本，不立即开始全量推理。

前置条件与动作：

1. 明确 E/NC/SAD/LOW/HIGH2/HIGH3 的路径、哈希、设备、cwd 和有效参数；保持现有 Forward 和归一化，不擅改 HDE。
2. 先处置 KI-09：现有入口即使换 results_dir 仍会覆写 test_opt.txt。不得把保护旧结果等同于保护全部记录。
3. 设计独立 run 目录与不覆盖写入策略，记录 Git SHA 及工作区差异；修复路径/日志前提交原因、影响、兼容性和验证方案供审核。
4. 明确使用 cycle_gan、single、GPU 0；这些是当前本机启动适配，不是论文原始超参数。当前 test.py 仍将测试 batch 固定为 1。
5. 用户批准后先复算 1 张已有小样本，再检查少量代表性分辨率，特别是 2048×2048 或 2560×1600。当前不执行，也不以此授权全量。
6. 比较与现有 results_uvtd_10 的数值，记录浮点与 uint8 差异及合理容差依据；结果不一致时保留证据，不直接归因于权重。

**最小验收**：独立输出有完整 run 记录；模块加载正确；shape/范围/有限值正确；旧结果、权重和旧 opt 记录未被覆盖；能解释重放结果及大图资源边界。现有 10 张只作为候选证据，不能提前写成已认证。

## P1：数据资产盘点和准备

**目标**：获得独立可引用的数据版本、划分与标签规范。

- 固化 UVTD Raw/Reference 文件清单和配对关系，核实官方 train/val/test；5380 是全集数量，不擅称测试集。
- 定位 UVTD 语义标签和检测真值，检查类别、文件名、尺寸/坐标、缺失/空标注和 split。
- 定位 Flickr2K，检查来源、版本和实际数量；不使用 UVTD Reference 代替空气域。
- SUIM train_val 已盘点为 1525 对；仍需建立 train/val 列表、内容级跨 split 重复核验、标签有效性检查。
- 核实本地 SUIM 1635 与论文 1634 的差异；不得自动删图、补图或移动 TEST。
- 保留 TEST 110 张为最终评价；处理标签时保持原图/Mask 对齐，离散标签不能用平滑插值创造新类别。

**最小验收**：每项资产有来源、唯一清单/版本、划分、类别/ignore 规则和有效性报告。缺失资产标记阻塞，不用假标签冒充。盘点本身不授权复制、转换或覆盖数据。

## P2：Stage 1 训练流程重建

**论文要求**：p.45-46 式(1)-(6)，固定 E、训练 G；UVTD/Flickr2K 不配对；Lsr+Lrec_a+0.1Lrec_u，margin=1；p.47 为 Adam、lr=1e-4、batch=2、50+50 epoch。

- **已有**：VGG、SAD、通用训练入口；不能把 SAD 与 G 的高层接口匹配当作逐层认证。
- **缺失**：双域采样、随机裁剪、两路重建、排序、阶段配置和保存/交接。
- **拟改动位置，未实施**：新增独立 Stage 1 模型和双域 Dataset；按需要扩展训练选项。已有工厂支持动态模型，不预先认定必须改 train.py 或 SAD 内部结构。
- **最小可验证测试，未来授权后**：一批 256×256 数据检查三个损失有限；用构造相似度验证排序符号；反向时 E 无参数梯度、G 有梯度；阶段保存/重载保持输出一致。
- **正式训练门槛**：Flickr2K、训练划分、结构对应和实验记录全部明确后，再申请执行相应训练预算。

## P3：Stage 2 训练流程重建

**论文要求**：p.46 式(7)-(14)，两套独立的 C/D，固定 E/G/CLIP；Lsep+Lclip+2Lidt1+Lidt2；p.47 为 lr=1e-4、batch=2、100+100 epoch。

- **已有**：FE 类、NC、SAD，以及返回多层列表的本地 CLIP；不需要重新发明图像编码器。
- **缺失**：独立 D、身份分支、CLIP 第 2-4 层与列表索引的明确映射、四项损失、阶段优化/保存。
- **拟改动位置，未实施**：独立 Stage 2 模型、FE 实例组织、CLIP 适配和阶段配置；必要时修正公共权重加载，但保持 P0 基线不受影响。
- **最小可验证测试，未来授权后**：C/D 不共享参数，四项损失有限；验证 C/D 梯度非零、E/G/CLIP 参数不更新，同时梯度能通过冻结网络回到 C；身份支路不自行增加一次 C。
- **正式训练门槛**：Stage 1 G 的来源、冻结设置、CLIP 输入单位/插值/层映射及数据划分已确定。

## P4：Stage 3 训练流程重建

**论文要求**：p.45 Fig.2、p.46-47 III.D、式(15)，内容分层增强、G、U-Net，Ltask=CE(T(Xenh),mask)；lr=1e-4、batch=2、50+50 epoch。

- **已有**：LOW/HIGH2/HIGH3、NC/SAD、U-Net 定义和 CE 函数。

- **数据阻塞**：当前 UVTD 语义标签未定位。合成标签只能用于将来的接口测试，不能算论文训练数据或正式训练完成。
- **拟改动位置，未实施**：Stage 3 模型入口或 cycle_gan_model.py、任务 Dataset/标签编码、任务权重路径、CE 参数及阶段配置。结构修正与纯接口修复必须分别说明。
- **最小可验证测试，未来授权后**：一批原图/标签同步处理，增强→logits→CE 可反向；检查类别范围、ignore、空间对齐、任务输入范围和增强模块梯度；验证保存/重载。
- **正式训练门槛**：确认 C/T 是否更新、E/G 冻结、任务模型初始化，以及 LOW/HDE 等论文差异的处理方案；不凭缺少图示锁标记自行推断。

## P5：SUIM 分割评价

**论文要求**：p.47-49，U-Net 和 DeepLabv3+，mIoU、mPA。SUIM TEST 110 张只用于最终评价。

- 先认证增强输入和任务模型/权重；数据集附带 .hdf5 不自动等同于论文模型。
- 明确论文采用的类别集合、背景是否计入、ignore 规则、resize/标签映射、指标实现及官方划分。
- 比较 Raw 和认证增强结果，使用同一任务网络、权重和评价协议；不为某种增强单独调整阈值或预处理。
- **最小验收**：有效像素与混淆矩阵可核查，逐类及总体指标可复算；完整样本数及失败数记录一致。评价本身不等于重新训练任务模型。
